User guide

Hivemind runs AI models on your own laptop and phones. The AI works on your devices, with no account and no cloud (unless you add one yourself).

1. Install

Android: install Hivemind from Google Play and allow notifications.

Windows and Linux: follow How to install, step by step with pictures: download, unzip, start Hivemind, allow it on your home network, pair it with your phone. On the phone, Devices → Add your computer → Send link to computer sends you the address of this website (by e-mail, a message or Quick Share).

The program and the AI engine come together; nothing else to install. Models are downloaded inside the app.

Windows blocks the app

Hivemind isn't code-signed yet, so Windows is careful with it (more in How to install → Something didn't work):

  • "Windows protected your PC" (SmartScreen): click More info → Run anyway. Unblocking the zip before unzipping avoids it.
  • "Smart App Control blocked an app that may be unsafe" (Windows 11): there's no "run anyway" for one app. You can turn Smart App Control off in Windows Security → App & browser control → Smart App Control. On some Windows versions it can't be turned back on without reinstalling Windows, so decide carefully, or wait for the Microsoft Store version, which is signed.

2. Your first chat (Solo)

  1. Download a model first (Models).
  2. Open Solo, pick the model at the top, press Load. Large models take a while on a phone or an older laptop.
  3. Type and press Enter (Shift+Enter for a new line).

Above the chat:

  • Saved chats (clock): every chat is saved after each answer. Tap one to continue it, or rename or delete it.
  • Think (Qwen3 models): on, the model thinks before answering (better for hard questions); off, it answers at once.
  • Instructions (sliders): tell the model how to answer, e.g. "Answer in Croatian" or a ready-made one such as Teacher or Translator.
  • Export saves the chat as a Markdown file. New chat starts over (the old one stays saved).

Under each message: Copy, Read aloud, Answer again (the last answer) and Edit and ask again (your questions).

Files and pictures: the paperclip attaches a PDF, Word, Excel, PowerPoint, EPUB or text file; ask about it in the same message. A file too long for the model offers Team → Document. Pictures need a model marked "reads pictures" (e.g. Qwen3-VL 2B).

3. Models

  • Catalog: every row says Fits this device, Fits with Big Model (with your helpers) or Too big. Search, filter by kind (chat, reads pictures, voice and embeddings), Only what fits, sort by size. Select several and download them together; you accept each model's license first.
  • Add from a Hugging Face link: paste a link to a .gguf file to add a model that isn't in the catalog. The download is checked like the others.
  • On this device: what's stored; delete to free space; Send to… copies a model to a paired device over Wi‑Fi (or to all helpers at once).
  • Other devices: what your other devices have; the main device can delete a helper's model.

A good start: Qwen3 4B Instruct on a laptop or a strong phone, Qwen3 1.7B on an older phone, Qwen3-VL 2B for pictures.

4. Add your devices

  1. Put all devices on the same Wi‑Fi and start Hivemind on each.
  2. On the device you're adding (a phone): Show pairing code (Devices screen, or Status on a helper).
  3. On the main device (the laptop): Devices → Add device. Pick the phone under Found nearby and type the 6-digit code, or scan the QR code with another phone.
  4. Accept on the phone. From then on they recognise each other, even when IP addresses change. A device added by the main device becomes a Helper by itself.

The same steps with pictures: How to install → Pair with your phone.

Two phones of the same model? Rename them from the laptop: the pencil next to the name on the Devices screen.

Several devices at once: a connection password

  • On each device: Settings → Connection password. Type your own (at least 6 characters) or tap Random numbers, then Save password. The 6-digit code keeps working too.
  • On the main device: Devices → Add device, tick several devices under Found nearby, keep One password for all on and type it once. Or switch it off and type each device's password (or the code on its screen).
  • A long list: Add from a list (CSV). One device per line: address,password,name (an IP address or the name shown under Found nearby). Lines without a password use the one you type in the dialog. Excel's semicolons work too.
  • A device that knows the password is added without asking. To be asked anyway: Ask me before accepting in its Settings. After 5 wrong passwords a device refuses the password for a while.

Limits for a device

On the main device: Devices → a device → Limits. Processor: use at most a share of its processor (fewer threads). Memory: give Big Model and Team at most a share of its RAM. Skip it when busy: leave it out of new jobs while its processor is busier than you set (phones report only Hivemind's own use).

Main, Helper, Monitor

The sign in the top-right corner shows this device's role; tap it to change it.

  • Main device (usually the laptop): runs Solo, Big Model, Team and Connect, and collects the others' status.
  • Helper (phones): lends memory to Big Model or works on Team parts. Its screen shows what it's doing, its temperature and battery. Stop helping any time.
  • Monitor (e.g. an old tablet): only shows the Dashboard of all devices.

5. Big Model

For models too big for one device: the laptop keeps part of the model, the phones hold the rest, and every word passes through all of them over Wi‑Fi.

  1. The model must be on the main device. The helpers don't need it: they receive their part when it starts (and keep it in a cache for next time).
  2. Big Model → 1 · Pick a model → 2 · Choose devices (the suggestion uses the fewest devices that fit) → 3 · Check the fit → Start Big Model.
  3. Chat as in Solo. Stop and free devices when done.

If a phone drops out (Wi‑Fi, battery), the chat is kept: Reload without it, or wait for it and retry.

Faster: Settings → Big Model → Draft model: Auto (a small model of the same family on the laptop guesses words, and the big one checks them; the answers stay the same) and Context in 8 bits. Fewer devices is faster: each one adds a Wi‑Fi hop to every word.

6. Team

For long work: every device runs its own model on parts of the job, and one writes the final answer.

  1. 1 · Job type: Long document / PDF, Research / web pages, Code / many files, Batch work (translate or classify many items), Multi-view (several "experts", then merge or vote).
  2. 2 · Input: files (PDF, Word, Excel, PowerPoint, EPUB, text; scanned PDFs are read from their pictures), pasted text, web addresses or a folder of code.
  3. 3 · Devices and their models, 4 · Who writes the final answer (the strongest model), then Start job.

Results stay under Past jobs to reopen, copy or save. A notification tells you when a long job is done.

7. Connect: your AI for other apps

Local API: Connect → switch it on. Tools that support Ollama or OpenAI (Open WebUI, Obsidian plugins, Continue, Home Assistant, scripts) use the address http://127.0.0.1:11434 and the model hivemind (the loaded model). It also does pictures, tool calls and embeddings (download an embedding model such as Nomic Embed Text).

Other devices on the Wi‑Fi: switch on "Allow other devices on the Wi‑Fi"; they need the key shown there. Apps on the same device never do.

If an app asks for a different model: Settings → "If an app asks for another model": Ask, Switch or Refuse.

Ask about text

  • Windows: copy text in any app and press Ctrl+Alt+Space. Or Connect → Ask about the clipboard, or the tray icon menu.
  • Android: select text → Ask Hivemind, or Share → Hivemind (text, links, photos).
  • Then: Answer, Summarize, Explain, Translate, Rewrite, Ask, or Make it an action (an alarm, timer, calendar event, map or message draft: you see it first, and nothing happens until you tap it).
  • Voice: the microphone in the text box. On computers, download Whisper base in Models first. Read aloud speaks the answer.
  • Android assistant: Android Settings → Apps → Default apps → Digital assistant app → Hivemind. A long press on the power or home button gives Hivemind the text on your screen (and a screenshot, if allowed).
  • Notifications (Android): Connect → Notification digest: a summary of your latest notifications, and replies you check and send yourself.

8. Useful settings

  • Language: System, English or Hrvatski.
  • Load the last model at start: the API and Ask about text work right after a restart.
  • Keep running when the window closes and Start with Windows: the laptop keeps helping from the tray (next to the clock). Quit from the tray icon's menu.
  • Context size: longer remembers more of the chat but needs more memory.
  • Safety guards: a helper pauses when too hot, and in Background mode at low battery.
  • About: the version and build date; it tells you when another device has a newer build.

Keep phones helping

Many phones (Xiaomi/HyperOS, Honor/MagicOS, Samsung) stop apps in the background. On a helper, the Status screen (and Settings) shows Keep helping in the background with the steps for your phone's brand and a button for each settings page. Do it once.

Best for long jobs: phones plugged in, in Dedicated mode (Status screen), with the screen on.

Ads (Android)

The Android app shows one small ad, marked Ad, at the end of Home, Devices, This device, Models and Dashboard; never in chats or jobs. Tap Remove ads next to the role sign and watch one short video: no ads on that device for 10 hours. Your chats and files never leave your devices; ads are shown by Google. In the EU, UK and Switzerland the app asks for your consent first, and ads come only after you answer. Settings → Privacy has the privacy policy and, where Google requires it, Privacy options to change your choice.

Report an answer: AI answers can be wrong or offensive. The flag under an answer (or Report under a result) writes a report to us; you see all of it, and it goes by e-mail only when you send it.

Updating

Phones update from Google Play. Computers: download the new version and put it in place of the old one (how). All devices should run the same build: Big Model needs the same engine everywhere. Settings → About and the Devices screen show each device's build.

Troubleshooting

  • Devices don't find each other: the same Wi‑Fi (not a guest network); on Windows allow Hivemind on private networks; or type the other device's address (shown on its pairing code) instead of "Found nearby".
  • Android 17 phones: allow Hivemind on your network when Android asks (Nearby devices). Said no? Devices → Allow, or Android's Settings → Apps → Hivemind → Permissions → Nearby devices → Allow.
  • A phone stops helping: Keep phones helping; check the Dashboard for heat or battery pauses.
  • The model doesn't fit or is very slow: pick a smaller one ("Fits this device"), or use Big Model with helpers. Close other big apps.
  • Big Model is slow: fewer devices, 5 GHz Wi‑Fi, the draft model on, phones close to the router.
  • Something else: Settings → About shows the version; tell us what you did and what happened.
